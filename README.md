# ميزان — نظام إدارة مكتب المحاماة

نظام متكامل لإدارة مكاتب المحاماة في العراق، بواجهة عربية كاملة، مبني على **React + Supabase** ويعمل مجاناً بالكامل.

**الرابط:** https://aliyaseenhasn-hue.github.io/Mylegal/

## المزايا

- **الموكلون:** ملف كامل لكل موكل (أفراد وشركات)، ترقيم تلقائي، أرشفة، مراسلة واتساب.
- **القضايا:** رقم ملف تلقائي، نوع الدعوى ودرجة المحكمة بالمسميات العراقية، صفة الموكل، الخصم ووكيله، المحامي المسؤول، الأولوية.
- **الجلسات:** سجل زمني لكل قضية، تسجيل ما جرى والقرار، **جدولة الجلسة القادمة تلقائياً**، تقويم شهري ورول جلسات قابل للطباعة.
- **المهام:** مواعيد الطعن والمراجعات، إسناد لأعضاء الفريق، تذكير قبل الاستحقاق.
- **المالية:** سندات قبض مرقّمة تُطبع (مع المبلغ كتابةً)، المصاريف (مستردة أو على المكتب)، الأتعاب المتبقية، بالدينار والدولار، زين كاش وكي كارد.
- **الوكالات:** تواريخ الإصدار والانتهاء مع تنبيه قبل 30 يوماً.
- **المستندات:** أرشيف محمي (Storage خاص) لا يُفتح إلا بروابط مؤقتة لأعضاء المكتب.
- **التقارير:** الذمم المتبقية، الحركة الشهرية، أداء المحامين ونسبة الكسب، إحصاء القضايا، وتصدير Excel.
- **التنبيهات:** توليد يومي تلقائي (pg_cron) للجلسات والمهام والوكالات، مع عدّاد لحظي.
- **الفريق والصلاحيات:** مالك، مدير، محامٍ، محاسب، سكرتير — مفروضة في قاعدة البيانات (RLS) وليس في الواجهة فقط.
- **سجل النشاط:** كل إضافة وتعديل وحذف باسم منفذها ووقتها.
- **عزل تام بين المكاتب:** يمكن لأي مكتب التسجيل، ولا يرى أي مكتب بيانات غيره.
- **استعادة الحساب:** نسيت كلمة المرور (رمز من 6 أرقام عبر البريد)، نسيت البريد (يُعرض جزء منه برقم الهاتف)، تغيير البريد.
- **لوحة المشرف العام:** كل المكاتب والحسابات، إيقاف/تفعيل، إعادة تعيين كلمة المرور، تغيير البريد.
- وضع ليلي، يعمل على الهاتف ويمكن تثبيته كتطبيق (PWA)، بحث شامل.

## البنية

```
web/                  واجهة React (Vite)
supabase/migrations/  مخطط قاعدة البيانات والصلاحيات والدوال
supabase/functions/   دوال طرفية: تسجيل مكتب، إدارة الفريق
legacy-django/        النسخة الأولى (Django) للرجوع إليها فقط
docs/                 وثائق
```

## التشغيل محلياً

```bash
cd web
cp .env.example .env
npm install
npm run dev
```

## النشر

الواجهة تُبنى وتُنشر على GitHub Pages (فرع `gh-pages`):

```bash
cd web && npm run build
# ثم انشر محتوى web/dist إلى فرع gh-pages
```

قاعدة البيانات والملفات والمصادقة على Supabase (الخطة المجانية).

## تفعيل إرسال رموز استعادة كلمة المرور (مجاني عبر Gmail)

1. فعّل التحقق بخطوتين في حساب Google، ثم أنشئ **كلمة مرور تطبيق** من: https://myaccount.google.com/apppasswords
2. في لوحة Supabase: Edge Functions ← Secrets، أضف:
   - `GMAIL_USER` = عنوان Gmail المرسِل
   - `GMAIL_APP_PASSWORD` = كلمة مرور التطبيق (16 حرفاً)

إلى أن يُضبط ذلك، يظهر للمستخدم أن الخدمة غير مفعّلة ويُطلب منه مراجعة مدير المكتب.
