# نظام إدارة مكتب المحاماة

نظام متكامل لإدارة الموكلين والقضايا والمهام والأتعاب مبني بـ **Django**.

---

## 🚀 طريقة التثبيت والتشغيل

### 1. المتطلبات
```bash
Python 3.10+
pip
```

### 2. إنشاء بيئة افتراضية
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

### 3. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 4. إعداد قاعدة البيانات
```bash
python manage.py migrate
```

### 5. إنشاء حساب المسؤول
```bash
python manage.py createsuperuser
```

### 6. تشغيل الخادم
```bash
python manage.py runserver
```

ثم افتح المتصفح على: **http://127.0.0.1:8000**

---

## ⚙️ تشغيل التنبيهات التلقائية (Cron Job)

لتوليد التنبيهات يومياً، أضف هذا الأمر إلى المجدول:

```bash
# Linux - crontab -e
0 8 * * * /path/to/venv/bin/python /path/to/manage.py generate_notifications

# Windows Task Scheduler
python manage.py generate_notifications
```

## 📋 مميزات النظام

### 👥 إدارة الموكلين
- إضافة وتعديل وحذف بيانات الموكلين
- البحث بالاسم والهاتف ورقم الهوية
- عرض تفصيلي لجميع قضايا كل موكل

### ⚖️ إدارة القضايا والملفات
- أنواع متعددة: مدني، جنائي، تجاري، أسرة، عمالي...
- حالات القضية: نشطة، موقوفة، مغلقة، مؤرشفة، مكسوبة، مخسورة
- تتبع الجلسة القادمة مع تنبيه تلقائي
- **أرشفة القضايا** بنقرة واحدة

### ✅ إدارة المهام
- أنواع مهام: جلسة محكمة، تقديم مستند، متابعة، اجتماع...
- أولويات: عاجلة، عالية، متوسطة، منخفضة
- حالات: معلقة، قيد التنفيذ، مكتملة، ملغاة
- تحديد موعد التذكير لكل مهمة
- عرض المهام المتأخرة والقادمة بشكل واضح

### 💰 إدارة الأتعاب
- تسجيل إجمالي أتعاب كل قضية
- تتبع الدفعات المدفوعة مع الإيصالات
- **احتساب تلقائي** للمبلغ المتبقي
- شريط تقدم بصري لنسبة السداد
- تقرير مالي شامل لجميع القضايا

### 📁 إدارة المستندات
- رفع ملفات لكل قضية (PDF, Word, Excel...)
- تصنيف: عقد، أمر محكمة، لائحة، إثبات، توكيل، حكم...

### 🔔 نظام التنبيهات
- تنبيه تلقائي للمهام المتأخرة
- تنبيه مسبق قابل للضبط (افتراضي: 3 أيام)
- مركز تنبيهات متكامل
- عداد التنبيهات غير المقروءة في الشريط الجانبي

### 📊 لوحة التحكم
- إحصائيات فورية: عدد الموكلين، القضايا، المهام
- ملخص مالي: الأتعاب، المدفوع، المتبقي
- قائمة المهام المتأخرة
- قائمة مهام الأسبوع القادم
